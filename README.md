# hoparoma.github.io

Marketing and legal pages for the Hoparoma iOS app.

Published at <https://hoparoma.github.io>.

## Pages

| URL | Purpose |
|---|---|
| `/` | Landing page (App Store Marketing URL) |
| `/privacy.html` | Privacy Policy (App Store required) |
| `/terms.html` | Terms of Use |
| `/support.html` | Support contact + FAQ (App Store required) |

## Stack

Static HTML + a single `style.css`. No build step, no JavaScript, no external fonts or scripts. System font stack for the body, serif for display type.

## Source of truth

Legal content is mirrored from [`hoparoma-ios`](https://github.com/hoparoma/hoparoma-ios) at `docs/legal/`. When the markdown source changes, mirror the edit here.
